Reference / 01

Before you run it.

The model expects feature names and values that match its training pipeline.

  • Categories. Use the supplied options, which should match the values accepted by your model.
  • Ordinal ratings. Satisfaction and involvement use dataset levels from 1 to 4.
  • Numeric fields. Enter non-negative whole numbers within plausible dataset ranges.
  • Consistency. Keep career durations logically consistent, such as years in a role not exceeding total tenure.
